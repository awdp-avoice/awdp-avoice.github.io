February 6, 2024




PUA，一场“勇敢者的游戏”



一、操纵关系评估测试


如果您正处于一段操纵关系中，可以尝试评估一下操纵关系的利害程度。自由既能提升你的关系质量，又能帮助你结束一段操纵关系，请试着期待自由能给你带来的各种可能性，这将为你提供一种全新的思考视角，帮助你决定停留在这样一段关系中，还是尝试改变，彻底为这段关系画上句号。

孤立

操纵者（伴侣）是否试图让你远离他人？

          是                   否

个人活动

操纵者（伴侣）是否试图操纵你的个人活动？

          是                   否

资源：教育、工作、金钱

操纵者（伴侣）是否试图干涉你接受教育、工作或花钱？

          是                   否

身体机能与健康

操纵者（伴侣）是否试图操纵你的身体机能和健康？

          是                   否

亲密关系

一般情况下，操纵者（伴侣）是否试图操纵你的亲密关系？

          是                   否

孩子（如并未牵扯孩子，请跳过此部分）

操纵者（伴侣）是否试图操纵你与孩子的关系？

          是                   否

监视

操纵者（伴侣）是否试图监视你的一举一动？

          是                   否

恐吓

操纵者（伴侣）是否为了让你服从而故意吓唬你？

          是                   否

威胁伤害

操纵者（伴侣）是否为了让你服从而威胁你？

          是                   否

惩罚或真实的伤害

操纵者（伴侣）是否惩罚你或真的伤害了你？

          是                   否

危险评估：

操纵者（伴侣）曾威胁要杀了你或伤害你？

          是                   否


操纵者（伴侣）曾掐住你的脖子，使你窒息？

          是                   否


操纵者（伴侣）曾对你施加身体暴力？

          是                   否


操纵者（伴侣）曾对你施加言语暴力？

          是                   否


操纵者（伴侣）曾对你施加其他危险？

          是                   否

如果危险评估“是”的答案多于或等于一个，你在这段关系中将有可能面临危险， 请向律师和警方寻求帮助，保护自身安全。


总的来说，情感操纵与其他关系的差异可归结为以下三点：鼓励、恐惧和惩罚。


二、继续还是结束——抉择时刻


无论你作出什么决定，请尝试独立思考：

1

若停留在关系中，你最担心的是什么？

2

若结束这段关系，你最担心的是什么？

3

为了达成你想要的结果，你能够做些什么，又能够改变什么？


结束一段关系非常痛苦，但随着时间的推移，痛苦会慢慢消散，不必继续待在那段被限制或需要小心翼翼相处的关系中，如果你已经尝试过挽救这段关系却没有成功，那么或许是时候结束并走出这段关系了。


操纵者也许会一再打压你的自尊，让你认为除了他，没有人愿意再爱你，但真正爱你的人会试着成全你，而不是把你拉入谷底。

A. 继续当前的关系 

以下建议能帮助你学会坚持自己，在当前关系中自由安全的生活：


  • 确保在亲密关系之外，与他人保持联系

  • 参加社会活动

  • 向专业人士求助

  • 弄清你的财务状况

  • 发展能让你经常外出的生活习惯

  • 给重要通讯录和文件备份

  • 列出你的目标清单

  • 列出你的底线清单，你的底线由你自己决定

  • 按时评估你的目标完成度

  • 试着寻找财务和子女抚养方面的法律顾问

  • 让操纵者参加暴力干预项目

  • 让操纵者接受药物或心理治疗


如果操纵者真的决心改变来停止操纵行为，操纵者也有可能只是改变策略，试图用其他方式继续操纵你，请记住，改变一个人是非常困难的，不要奢望操纵者可以轻易被改变。














B. 结束当前的关系 

你可以寻求哪些支持：

  • 反家庭暴力机构

  • 治疗或咨询（ 一旦咨询师不能为你提供帮助，请寻找更适合你的咨询师）

  • 医疗帮助

  • 向警方或律师求助


你需要做哪些准备：

  • 保护你的财产

  • 保护你的孩子

操纵者离开后，女性可能会觉得自己永远也无法好起来了，此时，向他人求助是十分重要的。希望你有足够的力量看到未来可能获得的自由，希望你生活在一个安全的地方，希望你在这段艰难的人生旅途中有知己陪伴。















三、疗愈伤痛


你有你自己的节奏，有权拥有自己的感受，有些事情是永远不可能被原谅的，但你要相信，即使选择不原谅，也能彻底痊愈。


找到适合自己的疗愈方法：

  • 重新做操纵者禁止你做你却想要做的那些事

  • 与操纵者曾试图让你远离的家人和朋友重建关系

  • 与支持你的人交往

  • 整理你的财务

  • 接受心理咨询和治疗

  • 参加社会活动

  • 锻炼身体

  • 关注自己

    —— 我现在感觉如何？我现在想做什么？

  • 与操纵者彻底切断联络


四、帮助他人


如果你身边有类似经历的被操纵者，可以尝试提供帮助：


  • 让她知道你在关心她

  • 问她是否需要帮助

  • 不要指挥她怎么做

  • 耐心倾听，允许她表达感受


在暴力发生后，很多施暴者被逮捕，又被迅速释放，他们怀着更强烈的愤怒找到受害者，后果难以想象。必要时，请向警察申请保护令，寻求官方保护。


最后，与操纵者的较量是一场勇敢者的游戏，但不意味着你会是输掉游戏的那一方，相信自己，保持信念，及时寻求支持和帮助，不再轻易相信本性难移的操纵者，让自己全身心沉浸于这场游戏之中，打出自己最好的组合牌，赢得比赛，你一定可以做到。


在PUA这场“游戏”中，你会是最终的赢家，并彻底终结这场残酷游戏。
